# 导航发布页 - 最终完整版

适合 PHP + MySQL 虚拟主机使用。这个版本不要求 PHP 自动写入 `config.php` 权限，支持后台管理、无限按钮、跳转/弹窗双交互、点击统计、稳定拖拽排序、图标/Emoji 分类选择、自定义上传图标、电脑端/手机端背景分别设置和安全登录限制。

## 功能

- 前台发布页/导航页。
- 后台地址：`/admin/`，前台不显示后台入口。
- 按钮不限数量，可新增、编辑、删除，并支持批量管理按钮。
- 每个按钮可设置：名称、描述、图标/Emoji、排序值、是否显示。
- 图标选择器已优化为分类选择：系统平台、常用入口、沟通客服、下载工具、活动权益、内容娱乐、安全状态。
- 内置代表 iOS 与 Android 的 SVG 图标，同时保留 🍎 / 🤖 等 Emoji 备选。
- 支持上传自定义图标，格式：png / jpg / jpeg / gif / webp，单个 ≤ 2MB；上传目录 `/i/`。
- 站点 Logo 支持后台直接上传替换，上传目录 `/l/`。
- 每个按钮支持两种交互方式：跳转链接、弹窗提示。
- 后台按钮列表支持 PC 鼠标拖拽、手机触屏拖拽和键盘上下键排序，拖完自动保存；也可以用“排序值”精确控制顺序。
- 站点设置里可分别配置“电脑端背景”和“手机端背景”：内置多套预设，也支持上传自定义背景图；前台使用 `background-size: cover` 自动适应屏幕。
- 自定义上传背景保存在 `/b/` 目录。
- 后台密码使用 `password_hash()` 加密保存到 MySQL。
- 使用 PDO 预处理、CSRF Token、登录失败限制、安全响应头、禁止访问 includes 目录。
- 安装完成后直接进入前台，不显示“安装完成”绿色提示。
- 如果数据库表被误删，访问域名会自动跳回安装页重新创建。

## 安装步骤

1. 上传压缩包到网站根目录并解压。
2. 进入文件管理，打开 `includes/config.php`，点铅笔编辑，手动填写数据库信息并保存。
3. 访问你的域名，会进入安装页。
4. 填写站点信息和后台账号密码，点击安装。
5. 安装完成后进入前台，后台地址：`你的域名/admin/`。

## 示例配置

```php
<?php
return [
    'db' => [
        'host' => 'localhost',
        'port' => 3306,
        'database' => 'f88753w',
        'username' => 'f88753w',
        'password' => '你的数据库密码',
        'charset' => 'utf8mb4',
    ],
    'setup_key' => 'MANUAL_CONFIG_MODE',
    'session_name' => 'NAV_ADMIN_SESSID',
    'force_https_cookie' => false,
    'login_max_failures' => 5,
    'login_window_minutes' => 15,
    'login_lock_minutes' => 15,
];
```

安装完成后，如果 `install.php` 没有被自动删除也没关系，程序会通过数据库里的管理员账号判断已安装并自动跳转首页。为了更安全，建议安装成功后手动删除 `install.php`。

## 本版检查结果

- 已使用 `php -l` 检查所有 PHP 文件语法。
- 已使用 `node --check` 检查前台与后台 JS 语法。
- PC 拖拽排序采用 `mousedown / mousemove / mouseup`，不依赖浏览器原生 HTML5 拖拽，兼容性更稳。
- 手机端拖拽排序采用 `touchstart / touchmove / touchend`，并使用 `passive:false` 防止拖动时页面误滚动。
- 键盘可访问：选中拖拽手柄后可用上下方向键调整排序。
- 前台布局已针对 PC、平板、手机断点优化：PC 两列按钮，手机单列按钮。
- 背景设置支持电脑端与手机端分别配置，上传背景会自动铺满适应屏幕。
- 图标/Emoji 选择已按常用场景重新整理，iOS / Android 图标使用内置 SVG，前台和后台均用 `object-fit: contain` 保持图标完整不被裁切。

## 本版新增：我的上传图标分类

后台“按钮管理”的图标/Emoji 选择器已新增“我的上传”分类。用户上传到 `/i/` 目录的自定义图标会自动按上传时间倒序显示，后续新增或编辑按钮时可直接点选复用，无需手动输入路径。

## 本版新增：批量管理与自定义 Logo

后台“按钮管理”新增批量勾选功能，可批量显示、隐藏、清空点击量、删除按钮。后台“站点设置”新增 Logo 上传功能，可直接替换前台顶部主图，不再需要手动输入图片地址。

## 本版新增功能

- 前台按钮搜索：用户可输入关键词搜索按钮名称、描述和分类。
- 前台按钮分类：按钮可设置分类，前台按分类筛选入口。
- 后台开关：可在“站点设置”中单独开启或关闭“按钮搜索”和“按钮分类”。
- 按钮新增“点击复制内容”交互方式：后台填写指定文本，用户点击按钮后自动复制。
- 旧版数据库自动升级：访问后台或前台时会自动补齐 `category`、`copy_content` 字段，并升级 `action_type` 支持 `copy`。
